# Fundamentals of Semiconductor Device Physics and Process Integration

WSQ courseware for **TGS-2024049339**, aligned to the Process Integration TSC (**ELE-SIS-3002-1.1**).

## Learning outcomes

- Identify semiconductor manufacturing process flows based on device physics.
- Determine follow-up actions for process integration issues and performance.

## Public learner materials

- `courseware/` - current trainer slide deck, learner slide PDF, Learner Guide and Lesson Plan.
- `activities/` - eight self-contained activity folders with procedures, scenarios, worksheets, evidence checklists and printable PDFs.

The assessment papers and answer keys are confidential trainer materials and are intentionally excluded from this public repository.

## Course information

- Duration: 2 days / 16 hours
- Classroom facilitation: 14 hours
- Assessment: 2 hours (Written Assessment + Case Study)
